Monkeypox Emotion Intelligence Platform
We Analyze Public Emotions in Real-Time

This project focuses on emotion classification of Monkeypox-related social media posts using advanced Natural Language Processing (NLP) and Deep Learning techniques. By analyzing over 800,000 tweets, the system identifies emotional responses such as fear, anger, sadness, trust, and anticipation. The extracted insights can help healthcare organizations, researchers, and policymakers better understand public concerns during disease outbreaks.
